# Badge press

The [badge press](https://bkg.club/badges.html) makes downloadable SVG and PNG
medallions, with a callsign and an optional curved OG tab. It loads the public
V2 roster; pasted JSON and uploaded files must also be V2 exports.

When a member holds several OG titles, the roster list shows all of them.
Choose the title in **OG title** to make one badge for that award. For example,
a member holding Canada and Alberta can download a **CANADA OG** badge and an
**AB OG** badge. Each badge keeps the existing single-tab design.

**Download all OG badges** includes one SVG per assignment, including all titles
held by the same member. ZIP filenames include the region key so separate
awards cannot overwrite one another. Titles use the stored assignments rather
than the member's current QTH. Members without a title start with an empty tab;
the callsign, tab text, and finish remain editable.
