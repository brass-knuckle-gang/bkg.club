NOW PLAYING: BRASS KNUCKLES KNOCK OUT

A boxing game that teaches Morse code. Sponsored by yours truly.
BETA!! This game is still in beta. Found a bug? Report it in the Brass Knuckle Gang Discord.

HOW 2 PLAY

Every opponent sends a Morse character before each punch. Key the same character back to dodge, then counter. All dits jab, all dahs hook, mixed characters throw combos. Fighters add characters in Koch order as you climb the ladder.

  • Z and X: dit and dah. Hold both to squeeze.
  • Left and right Ctrl or [ and ]: dit and dah, for a Vail adapter or any USB paddle adapter in keyboard mode.
  • Space or Enter: pick a fighter, ring the bell, pause. ← →: next or previous fighter.
  • 1 to 4: F1 to F4. On a phone, tap the buttons under the screen.

Click the game first so it gets ur keystrokes. Fighters and best scores are saved in this browser only.

🐛 It's a beta: if something breaks, tell us in the Discord with what you were doing and which browser or device you used.
